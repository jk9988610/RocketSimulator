# RocketSimulator

2D 火箭模拟器 — 组装火箭、设计启动链、发射入轨。

## 平台

- **原型**：GitHub Pages（Web）
- **目标**：Android APK（平板横屏）
- **云端**：Supabase（存档与同步，后期）

## 核心玩法

1. **组装** — 在横屏组装区拖放部件（圆台、指令仓、燃料箱、引擎、连接器等），支持对称放置与网格吸附
2. **启动链** — 为引擎、连接器、降落伞配置分阶段启动顺序
3. **发射** — 发射台起飞，节流阀、引擎开关、左右倾控制
4. **轨道** — 地球/月球/太阳引力，大气与卡门线，地图模式显示轨道与近远点
5. **远期** — 自动驾驶
