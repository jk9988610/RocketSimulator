# 2D 火箭模拟器 — 项目大纲与任务计划

> RocketSimulator 项目总体设计文档  
> 平台：先 GitHub Pages 原型，后 Android APK（平板横屏）  
> 协作：Cursor + 平板 Termux + Supabase

---

## 一、项目愿景

| 项目 | 说明 |
|------|------|
| **名称** | RocketSimulator（2D 火箭模拟器） |
| **平台** | 安卓平板（横屏）→ GitHub Pages 原型 → Termux 打包 APK |
| **核心玩法** | 组装火箭 → 设计启动链 → 发射 → 轨道飞行 →（远期）自动驾驶 |
| **协作** | Cursor（开发）+ 平板 Termux（APK 构建与真机测试）+ Supabase（云端） |

## 三、火箭部件目录（组装系统）

### 3.1 部件清单（自顶向下）

```
                    [鼻锥 ×2]（径向两侧燃料箱顶部）
                         │
    ┌────────────────────┼────────────────────┐
    │  [燃料箱]──[H型径向连接器]──[燃料箱]   │
    └────────────────────┬────────────────────┘
                         │
              [圆环连接器]（可断开）
                         │
              [圆柱燃料箱]
                         │
              [圆环连接器]
                         │
              [隔热片]（贴指令仓底部）
                         │
    ┌─[指令仓 + 宇航员]─┐
    │  [半球降落伞罩]   │  ← 半球底径 = 圆台顶径
    └────────┬─────────┘
             │
         [圆台]（截头圆锥）
             │
         [引擎 ×N]（推力方向可调）
```

### 3.2 部件属性表

| 部件 | 形状/示意 | 关键属性 | 可加入启动链 |
|------|-----------|----------|--------------|
| **圆台** | 截头圆锥 | 质量、直径 | 否 |
| **指令仓** | 舱体 + 宇航员 | 乘员、生存 | 否 |
| **降落伞** | 半球罩（底径=圆台顶径） | 展开时机、减速 | **是** |
| **隔热片** | 圆片，贴指令仓底 | 耐热 | 否 |
| **圆环连接器** | 上下对接环 | 连接/断开状态 | **是** |
| **圆柱燃料箱** | 圆柱 | 燃料量、质量 | 否 |
| **径向连接器 (H)** | 侧视如 H | 开关、连接两箱 | **是** |
| **鼻锥** | 尖锥 | 气动（后期） | 否 |
| **引擎** | 喷口 | 推力、燃料消耗、摆角 | **是** |

### 3.3 连接规则

- **纵向**：圆环连接器串联（指令仓 ↔ 燃料箱 ↔ 引擎）
- **横向**：H 型径向连接器连接并排燃料箱（如 `A─H─B`）
- **吸附**：靠近时网格吸附 + 连接点吸附
- **对称**：以组装区竖直中线为轴，镜像放置与同步操作

## 四、UI / UX 设计

### 4.1 横屏布局

```
┌──────────┬────────────────────────────────────────────┐
│ 物件栏   │              组装区（黑底）                  │
│ (窄)     │         │ 对称轴（隐藏竖线）│                  │
│          │         │                  │                  │
│ [部件列表]│    ← 网格吸附 + 拖放组装 →                  │
│ 可上下拖 │                                              │
│          │                              [发射] ← 右上角  │
├──────────┤                                              │
│ [对称]   │                                              │
│ [启动链] │                                              │
└──────────┴────────────────────────────────────────────┘
```

手机横置后：左侧物件区（比组装区窄），右侧组装区。组装区有隐藏网格和隐藏竖直对称轴（居中）。

### 4.2 交互规范

| 操作 | 行为 |
|------|------|
| 从物件栏拖入 | 在组装区放置新部件 |
| 组装区内拖动 | 移动已放置部件 |
| 单击 | 选中 / 取消选中 |
| 多选 | 依次点击多个部件 |
| 多选拖动 | 整组一起移动 |
| 对称开关 ON | 选中部件在轴另一侧出现镜像，操作同步 |
| 靠近吸附 | 网格点 + 连接点对齐 |

### 4.3 启动链设计模式

点击「启动链」后，左侧栏切换为启动链设计栏：

```
启动链设计栏
├── [+ 添加启动级]
├── 启动级 3  ← 数字越大 = 越先执行
│   └── [+ 添加目标] → 在组装区点选（引擎/连接器/降落伞）
├── 启动级 2
│   └── ...
└── 启动级 1  ← 最后执行
```

**启动链步进按钮**：每次按下执行下一个启动级（从编号最大的级开始）。

## 五、发射台场景

### 5.1 场景切换

组装区右上角 **[发射]** → 切到发射台场景：

- 地表梯形发射台
- 底部为可缩放（双指）但不可平移的地球背景
- 火箭按组装结果生成在台上

### 5.2 发射 UI（右下角为主）

```
        [引擎总开关]     ← 控制当前最高编号启动级上的引擎
            │
        [节流阀]         ← 纵向滑条（Throttle，类似油门）
            │
    [启动链查看]（只读，暂不支持编辑）
            │
      [启动链步进]       ← 每按一次执行下一启动级（从编号最大开始）
```

### 5.3 飞行控制（第四象限中央）

```
      [ ← 左倾 ]    [ 右倾 → ]
```

- 控制引擎摆角 / 推力矢量
- 默认作用于「当前火箭上编号最大的引擎」

### 5.4 地图切换（左上角）

| 模式 | 内容 |
|------|------|
| **现场** | 2D 侧视发射与飞行 |
| **地图** | 火箭=三角形；地球、月球、太阳；公转轨道 + 飞行轨道；标注 **近点（Periapsis）**、**远点（Apoapsis）** |

## 六、物理与环境模型

### 6.1 重力场（分阶段）

| 区域 | 重力模型 | 说明 |
|------|----------|------|
| **地表 / 近地** | 地球重力 g ≈ 9.81 m/s²（可随高度衰减） | 发射台默认 |
| **大气层内** | 空气阻力 + 大气密度随高度变化 | 影响推力与减速 |
| **卡门线** | 约 100 km | 大气层边界参考线 |
| **近地轨道** | 地球点质量引力 | 开普勒轨道 |
| **地月空间** | 地球 + 月球引力叠加 | 转移轨道 |
| **深空 / 太阳系** | 太阳 + 主要天体（行星后续补） | 「天空重力」 |

### 6.2 轨道要素

- **近点（Periapsis）**：轨道上距中心天体最近点
- **远点（Apoapsis）**：轨道上最远点
- 地图模式绘制轨道并标注

### 6.3 仿真精度（分档实现）

1. **MVP**：恒定重力 + 简单阻力
2. **V1**：高度相关大气 + 地球引力
3. **V2**：二体 / 多体 + 轨道线预测
4. **远期**：自动驾驶（姿态 + 轨道机动）

## 十二、首迭代建议

从 **阶段 0 + 1.1～1.2** 开工，第一个可演示版本应包含：

1. 横屏黑底组装区 + 左侧可滚动物件栏
2. 至少 3 种占位部件（圆台、燃料箱、引擎）可拖放
3. 隐藏网格与基础吸附
4. GitHub Pages 在线预览链接
