# 物理与环境模型

> RocketSimulator 当前物理实现的简化说明（Web 原型）

## 坐标系

| 场景 | 坐标 |
|------|------|
| **现场飞行** | 原点为发射台表面；+x 右，+y 下；32 px = 1 m |
| **地心力学** | 原点为地心；用于高度、轨道与引力计算 |
| **地图** | 日心坐标；太阳在原点，地球沿 AU 圆轨道 |

## 引力

### 地球

默认使用**地心矢量引力**（`ENV_CONFIG.vectorEarthGravity = true`）：

```
a = -μ_earth · r / |r|³
```

其中 `r` 为火箭相对地心位置（米），`μ_earth = 3.986×10¹⁴ m³/s²`。

### 月球

月球引力已启用（`ENV_CONFIG.moonGravity = true`）。月球位置随仿真时间在地心轨道面上公转：

```
a_moon = μ_moon · (r_moon - r) / |r_moon - r|³
```

`μ_moon = 4.905×10¹² m³/s²`，轨道半径 384400 km。

高轨道与地月转移段会感受到摄动；近地发射阶段影响可忽略。

### 太阳

日心引力默认关闭（`heliocentricGravity = false`），飞行尺度相对地球轨道极小而省略。

## 大气

| 参数 | 值 |
|------|-----|
| 卡门线 | 100 km |
| 标高 | 8.5 km |
| 密度模型 | `ρ/ρ₀ = exp(-h/H)`，h ≥ 100 km 时 ρ = 0 |

阻力与空气密度成正比；降落伞展开后使用独立阻力系数。

## 仿真时间

所有天体运动（公转、自转）由 `cosmosSimTimeS` 驱动：

- 随 `dt × timeWarp` 累积
- **暂停时 dt = 0**，宇宙全面静止

### 压缩周期（`SIM_PERIODS_S`）

真实周期过长，地图与自转使用可观察的游戏尺度：

| 天体 | 仿真一圈（秒） | 说明 |
|------|----------------|------|
| 地球自转 | 120 | 现场/地图可见自转 |
| 地球公转 | 200 | 地图日心轨道 |
| 月球公转 | 50 | 与自转同步（潮汐锁定） |
| 太阳自转 | 160 | 地图视觉 |

真实参考值见 `cosmos-scale.ts` 中 `REAL_PERIODS_S`。

## 轨道显示

近点/远点由 **vis-viva** 方程从当前位置与速度估算，非完整开普勒积分：

```
ε = v²/2 - μ/r
e = √(1 + 2εh²/μ²)
a = -μ/(2ε)
r_p = a(1-e),  r_a = a(1+e)
```

## 着陆（M5）

| 条件 | 阈值 |
|------|------|
| 最低飞行高度 | 15 m（否则不判定着陆） |
| 无伞安全触地速度 | ≤ 6 m/s |
| 有伞安全触地速度 | ≤ 14 m/s |
| 最大着陆倾角 | ≈ 18° |
| 降落伞建议 | 高度 < 800 m 且下降 > 25 m/s |

须保留指令仓；降落伞通过启动链 `applyStageAction` 展开。

## 燃料

所有未分离燃料箱**按剩余量比例同步消耗**（并联供油），各箱液位以相同速率下降。

## 配置入口

- 常数与开关：`web/src/launch/cosmos-scale.ts` → `ENV_CONFIG`
- 天体位置：`web/src/launch/cosmos-simulation.ts`
- 引力合成：`web/src/launch/gravity.ts`
- 大气：`web/src/launch/atmosphere.ts`

## 已知简化

1. 2D 侧视 — 无第三维与姿态动力学（仅俯仰角）
2. 无太阳/行星 N 体引力（除月球）
3. 地图轨道为相对地球局部示意，非精确日心轨迹
4. 月球在「现场」高空为天空装饰，位置与轨道角同步
